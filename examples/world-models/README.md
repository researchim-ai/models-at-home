# Synthetic world-model episodes

Toy 32×32 square-motion episodes, generated by `scripts/create-world-demo.py` with a fixed seed. Continuous `[dx,dy]` actions, `[x,y]` states, optional reward and terminal labels. Train: 16 independent episodes; validation: 4, each with 8 transitions. Units: pixels per transition; motion clamps at image boundaries.

For a pipeline demonstration only. These data do not establish robot, game or desktop dynamics quality. The smoke script also converts the same action vocabulary to discrete/hybrid contracts for implementation checks.
