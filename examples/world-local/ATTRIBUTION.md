# Breakout reference image

Cropped DIAMOND Breakout panel from frame 0 of `iris.gif` on the DIAMOND authors' project website:
https://diamond-wm.github.io/static/gifs/iris.gif
https://github.com/diamond-wm/diamond-wm.github.io

Authors: Eloi Alonso, Adam Jelley, Vincent Micheli, Anssi Kanervisto, Amos Storkey, Tim Pearce, François Fleuret.
Website content license: CC BY-SA 4.0, https://creativecommons.org/licenses/by-sa/4.0/ .
This derived crop (64×64, lower DIAMOND row) is distributed under CC BY-SA 4.0.

It is an initial screenshot from a published world-model demonstration, not an Atari ROM. A single image is repeated as a warm-start observation history; it does not supply the original demonstration's action history. CS:GO starting contexts are fetched with the official pretrained model assets and retain their real frame/action history.
