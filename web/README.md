# Models at Home · website

Самостоятельный двуязычный сайт проекта: английский и русский, реальные скриншоты
приложения, интерактивный обзор шести разделов, Research Lab с карточками блоков,
VLA-политики, порядок обучения, установка и FAQ. Тексты объясняют, как студия помогает
разобраться в устройстве моделей, создавать свои архитектуры и обучать их.

Визуальный стиль — исследовательская мастерская: графитовая типографика, красные акценты,
светлая бумага, нарисованная схема общего core и контрастный лабораторный раздел.
Сайт использует обычные HTML/CSS/ES modules. Внешних JS-библиотек, CDN, аналитики и
запросов к API студии нет. Шрифты и изображения хранятся локально.

## Запустить

Нужен Node.js 22.12+. Установка npm-зависимостей не требуется.

```bash
cd web
npm run dev
```

Откройте **http://127.0.0.1:4173**. Dev-сервер перезапускается при изменении исходников;
после правки обновите страницу браузера. Другой порт: `npm run dev -- --port 4180`.

## Собрать и проверить

```bash
npm run build
npm run check
npm run preview
```

`build` создаёт `web/dist/` со статическими `/`, `/en/` и `/ru/` страницами.
`preview` раздаёт именно готовую сборку. `check` проверяет паритет переводов,
HTML anchors/IDs, наличие изображений, локальные ссылки и маршруты production-сервера.
Сборки игнорируются Git. Сайт не меняет сборку и зависимости Electron-приложения.

## Как редактировать

- `content.js` — все английские/русские тексты, описания моделей и команды установки.
- `page.js` — HTML-шаблоны и общий layout. Сборка заранее рендерит оба языка.
- `style.css` — адаптивная вёрстка, типографика, цвета и анимации.
- `site.js` — вкладки, keyboard navigation, галерея, FAQ/menu и clipboard.
- `assets/screenshots/` — оптимизированные реальные кадры приложения в WebP.
- `scripts/` — dev/preview-сервер, сборка и проверка без дополнительных пакетов.

При изменении возможностей проекта обновляйте оба языка. Не добавляйте обещания о
непроверенных GPU-прогонах или несуществующих готовых установщиках: кнопки ведут на
исходники и инструкции. Ссылки на документацию используют GitHub `blob/HEAD`, чтобы
следовать default branch репозитория после публикации соответствующих изменений.

## Скриншоты и шрифты

Основные кадры получены из `../docs/screenshots/`. VLM-кадр взят из того же реального
packaged desktop smoke-сценария (`scripts/smoke-desktop.cjs`, результат `vlm.png`).
Веб-версии перекодированы в WebP без изменения содержимого интерфейса.
При обновлении приложения замените соответствующий WebP и проверьте alt-тексты.

Manrope и IBM Plex Mono self-hosted; их SIL Open Font License лежат в `assets/fonts/`.
У моделей и runtime собственные лицензии; ссылка в footer относится к Apache-2.0
лицензии `models-at-home/LICENSE`, а не переопределяет лицензирование всех компонентов.

## Разместить на хостинге

На любой статический хостинг загрузите **содержимое `web/dist/`**. Нужна обычная раздача
`index.html` в каталогах, без SPA fallback. Относительные пути позволяют разместить сайт
в подкаталоге. Команда сборки из корня репозитория: `npm --prefix web run build`,
выходной каталог: `web/dist`.

В этой задаче сайт создан локально; внешняя публикация не выполнялась.
